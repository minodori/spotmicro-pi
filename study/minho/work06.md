## 1. 핵심 원칙: 조립 시 90° 세팅

서보를 조립할 때는 **90°(전기적 중립)로 설정한 뒤 혼(Horn)을 결합**하는 것이 기본 원칙이다.
180° 범위 서보에서 90°는 정중앙이므로 양방향으로 ±90°의 최대 운동 범위를 확보할 수 있다.

**12개 서보 모두 90°에서 결합한다. 달라지는 것은 그때 다리를 어떤 자세로 잡고 있느냐다.**

| 관절 | 서보 (결합 전) | 이때 잡고 있을 다리 자세 | 결과 오프셋 |
|------|:--------------:|--------------------------|:-----------:|
| 어깨 (shoulder) | **90°** | 다리가 몸통에서 수직 하방 | ≈ 90 |
| 엉덩이 (upper) | **90°** | 대퇴부 수직 하방 | ≈ 90 |
| **무릎 (lower)** | **90°** | **무릎을 약 80° 굽힌 중간 자세** | 좌 ≈ 170 / 우 ≈ 1 |

무릎만 굽힌 자세로 결합하는 이유는 §3 참고. 어깨·엉덩이는 기준 자세에서 양쪽으로 움직이므로
중앙(90)이 맞지만, **무릎은 한 방향으로만 움직이므로 기준점을 가동 범위 끝에 두어야 한다.**

---

## 2. "직립 중립"은 관절마다 다르다

서보를 90°에서 조립했다고 해서, 로봇이 직립 자세를 취할 때 모든 서보가 90°에 있는 것은 아니다.  
`JetsonNano/servo_controller.py`의 offset 배열이 이를 보여준다.

```python
# [FL_무릎, FL_엉덩, FL_어깨, FR_무릎, FR_엉덩, FR_어깨,
#  RL_무릎, RL_엉덩, RL_어깨, RR_무릎, RR_엉덩, RR_어깨]
self._servo_offsets = [170, 85, 90, 1, 95, 90, 172, 90, 90, 1, 90, 95]
```

> **주의**: 위 배열은 Jetson 시절 **다른 개체**의 값이다. 오프셋은 혼이 스플라인에 물린 위치에 따라 개체마다 달라지므로 그대로 쓰면 안 된다. 현재 CM4 빌드의 실측값과 측정 절차는 [work11.md §6.6](work11.md) 참고.

| 관절 | offset 범위 | 의미 |
|------|-------------|------|
| **어깨 (roll/abduction)** | ≈ 90 | 다리 수직 하방 = 좌우 대칭 중립 → 90°가 실제 중립 |
| **엉덩이 (hip/upper leg)** | 85 ~ 95 | 대퇴부 직하방 ≈ 90° 근방 |
| **무릎 (knee/lower leg)** | 170 또는 1 | 좌/우 서보가 **거울 대칭으로 반전 장착** |

---

## 3. 무릎(lower) 서보 offset이 극단값인 이유

`angleToServo()` 함수를 보면 좌/우 무릎은 부호가 반대다.

```python
# FL Lower (왼쪽): 빼기
self._val_list[0] = self._servo_offsets[0] - self._thetas[0][2]  # offset=170

# FR Lower (오른쪽): 더하기
self._val_list[3] = self._servo_offsets[3] + self._thetas[1][2]  # offset=1
```

왼쪽과 오른쪽 무릎 서보는 물리적으로 **반대 방향으로 장착**되어 있기 때문에, 같은 "다리 완전히 편 상태(theta=0)"가:
- 왼쪽 무릎: 서보 **170°**
- 오른쪽 무릎: 서보 **1°**

에 해당한다. 즉 서보를 90°로 조립하고 혼을 달면, 그 상태는 "무릎이 약 80° 구부러진 중간 자세"가 된다.

### 왜 무릎은 편 상태로 결합하면 안 되는가

무릎은 기준 자세(다리를 편 상태, theta=0)에서 **한 방향으로만** 굽는다. 보행 중 최대 theta 는 약 130° 다.

무릎을 **편 상태**에서 서보 90° 로 결합하면 오프셋이 90 이 되고, 실제 보행에서 범위를 벗어난다.

```
왼쪽 무릎:  90 - 130 = -40    <- 동작 불가
```

**80° 굽힌 상태**에서 90° 로 결합하면 오프셋이 170 이 되어 정상 동작한다.

```
왼쪽 무릎: 170 - 130 =  40    <- 정상
```

어깨·엉덩이는 기준 자세에서 양쪽으로 움직이므로 중앙(90)에 두는 것이 맞고,
무릎은 한쪽으로만 움직이므로 기준점을 가동 범위 끝에 두어야 한다. 원칙("90° 에서 결합")은
같지만, **무릎은 그 90° 가 곧 기준 자세는 아니다.**

## 4. 실제 직립 자세 = IK가 계산한 각도

`servo_controller.py` 하단의 직립 목표 좌표:

```python
legEndpoints = np.array([[100,-100,87.5,1], [100,-100,-87.5,1],
                          [-100,-100,87.5,1], [-100,-100,-87.5,1]])
thetas = kn.initIK(legEndpoints)
```

발끝이 엉덩이 관절 아래 **100mm** 위치일 때, IK가 계산한 theta 값이 "직립 서보 각도"다.  
이 때 무릎은 완전히 펴지지 않고 **약간 굽혀진 상태**다.

> 다리를 완전히 펴면 역운동학(IK)이 특이점(Singularity)에 빠지고, 충격 흡수 능력도 사라지기 때문에 실제 보행 로봇은 무릎을 항상 약간 구부린 상태로 유지한다.

## 5. 조립 권장 순서

1. **서보를 90°로 설정** (12개 전부. 전기적 중립, 최대 범위 확보)
   ```bash
   python JetsonNano/examples/servo_check.py 4 90         # 인덱스로
   python JetsonNano/examples/servo_check.py raw 40 14 90 # 배선 전이면 보드/채널로
   ```
2. 서보가 90°인 상태에서, 아래 다리 자세를 잡고 혼 결합:

   | 관절 | 혼 결합 시 잡을 다리 자세 | 결과 오프셋 |
   |------|---------------------------|-------------|
   | 어깨 (shoulder/roll) | 다리가 몸체에서 수직 하방 | ≈ 90 |
   | 엉덩이 (hip/upper) | 대퇴부 직하방 | ≈ 90 |
   | 무릎 (knee/lower) | **무릎을 약 80° 굽힌 중간 자세** (§3 참고) | 좌 ≈ 170, 우 ≈ 1 |

   > 무릎을 "다리 완전히 편 상태"로 결합하면 오프셋이 90 이 되어 보행 시 범위를 벗어난다.
   > 좌/우 무릎은 거울 대칭으로 반전 장착되므로 굽히는 방향도 서로 반대다.

3. 조립 후 실측 조정 — `JetsonNano/examples/servo_check.py cal <인덱스>`
   (방향키로 1도씩 조정하며 기준 자세를 찾는다. 관절별 목표 자세를 화면에 띄워준다)
4. 측정값을 `servo_controller.py`의 `_servo_offsets` 배열에 기록

> **혼은 원하는 각도에 정확히 안 맞는다.** 스플라인 한 칸이 약 18° 이므로 가장 가까운 칸에 끼우고,
> 남은 오차(최대 9°)를 오프셋으로 흡수한다. 실측 오프셋이 80~95 사이에 흩어지는 것이 정상이다.
>
> 다만 **한 다리만 유독 크게 벌어지면 조립 이상을 의심할 것.** 실제로 FR-Upper 가 다른 Upper(80~81)보다
> 14° 튀었고, 원인은 서보 혼 이탈이었다 ([work11.md §6.13](work11.md)).

## 5.1 실측 조정 체크리스트 (RPi5, `test_servos_cali.py`)

`servo_controller.py`의 기존 `_servo_offsets` 값을 그대로 입력해서, RPi5로 이식한 뒤에도 실제 자세가 맞는지 서보별로 검증한다.

| 서보 번호 | 관절 | 입력할 각도 | 기대하는 실제 모습 |
|---|---|---|---|
| 0 | FL(왼앞) 무릎 | 170 | 하퇴부가 완전히 펴진 직하방 |
| 1 | FL 엉덩이 | 85 | 대퇴부 직하방 |
| 2 | FL 어깨 | 90 | 다리가 몸체에서 수직 하방 |
| 3 | FR(오른앞) 무릎 | 1 | 하퇴부 완전히 펴진 직하방 (왼쪽과 반대 방향 장착이라 값도 반대) |
| 4 | FR 엉덩이 | 95 | 대퇴부 직하방 |
| 5 | FR 어깨 | 90 | 다리가 몸체에서 수직 하방 |
| 6 | RL(왼뒤) 무릎 | 172 | 하퇴부 완전히 펴진 직하방 |
| 7 | RL 엉덩이 | 90 | 대퇴부 직하방 |
| 8 | RL 어깨 | 90 | 다리가 몸체에서 수직 하방 |
| 9 | RR(오른뒤) 무릎 | 1 | 하퇴부 완전히 펴진 직하방 |
| 10 | RR 엉덩이 | 90 | 대퇴부 직하방 |
| 11 | RR 어깨 | 95 | 다리가 몸체에서 수직 하방 |

순서대로 0번부터 11번까지 입력해서 각 다리가 기대하는 모습대로 움직이는지 확인한다.

- 전부 맞으면: 기존 오프셋이 여전히 유효 → RPi5 이식 성공.
- 특정 서보가 어긋나 있으면: 조립이 바뀌었거나 서보가 재장착된 것이므로 위 3~4번 순서대로 실측해서 `_servo_offsets` 값을 새로 기록한다.
