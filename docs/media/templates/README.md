# 자막 카드 템플릿

시연영상에서 **글자만 나오는 컷**에 쓰는 배경입니다. 1920×1080 PNG 이고, 캡컷에서
사진으로 불러온 뒤 그 위에 텍스트를 얹습니다.

| 파일 | 워드마크 | 쓰는 곳 |
|---|---|---|
| `card_kinetiq_top.png` | 좌상단 | **기본.** 목적 카드, 장 구분, 클론·설치 안내 |
| `card_kinetiq_bottom.png` | 우하단 | 화면 위쪽에 글이 많을 때 |
| `black_1080p.png` | 없음 | 순수 검정. 전환용, 워드마크가 방해될 때 |

## 캡컷에서 쓰는 법

```
1. 파일을 태블릿 갤러리에 저장
2. 재생헤드를 넣을 위치로
3. [+ 추가] → 사진 → 선택
4. 클립 끝을 드래그해 원하는 길이로   ← 사진은 기본 3초로 들어옵니다
5. [텍스트] → [텍스트 추가]
```

## 글자 얹을 때

- **가운데 정렬, 흰색.** 워드마크가 좌상단(또는 우하단)에 있으므로 본문은 화면
  중앙에 두면 겹치지 않습니다.
- **좌우 여백을 화면 폭의 15% 이상** 남기십시오. 폰으로 볼 때 가장자리가 잘립니다.
- 한 카드에 **다섯 줄까지**. 8초 안에 읽히는 한계입니다.
- 문단을 나눠 보이고 싶으면 텍스트 클립을 **두 개** 만들어 시작 시간을 0.5초
  어긋나게 두십시오. 빈 줄보다 확실합니다.

## 워드마크는 건드리지 마십시오

`K I N E T I Q` 의 자간과 위치, 밑줄 길이가 세 파일에서 같습니다. 카드가 여러 번
나올 때 **같은 자리에 같은 크기로** 있어야 한 편의 영상으로 읽힙니다. 카드마다
위치가 달라지면 산만해집니다.
