# checkpoints — 학습된 정책 가중치

대회 운영규정 제9조 제2항 제3호는 자체 개발 모델의 가중치를 **승인 절차 없이
누구나 접근할 수 있는 공개저장소에 게시**할 것을 요구합니다. 여기가 그 위치입니다.

| 파일 | 내용 |
|---|---|
| `policy.zip` | Stable-Baselines3 PPO 정책 |
| `vecnormalize.pkl` | 관측 정규화 통계 — **없으면 정책이 동작하지 않습니다** |
| `meta.json` | 이 정책이 기대하는 관측 모드와 학습 조건 |

```bash
make eval                                              # 또는
uv run python -m rl.eval --run checkpoints --command 0.3 0 0 --no-domain-rand
uv run python -m rl.eval --run checkpoints --render
```

`meta.json` 이 있어야 평가 쪽이 관측 모드를 알 수 있습니다. 없으면 디렉터리 이름으로
추측하는데, 가중치를 옮기는 순간 틀립니다 — **정책과 그 정책이 기대하는 관측은 한
곳에 같이 있어야 합니다.**

---

## 이 정책이 무엇이고 무엇이 아닌지

**`hist-clean`** — 관측에 관절 피드백을 쓰지 않고(실물에 없는 정보이므로) 명령 이력
5프레임으로 대신하며, **도메인 랜덤화 없이** 600만 스텝 학습했습니다.

### 측정값 (`--no-domain-rand`, 명령 vx 0.3, 20초 × 3회)

| 항목 | 값 | |
|---|---:|---|
| 전진 속도 | **0.171 m/s** | 규칙 기반 실물 0.050 의 **3.4배** |
| 생존 | 20.00 s | 3/3 완주 |
| 최대 무릎 각속도 | **972 °/s** | DS3235 정격 500 의 **194%** ⚠ |
| 최대 서보 토크 | 3.000 N·m | 포화 |
| 동체 높이 | 210.7 mm | 목표 247 (36mm 웅크림) |
| 실측 yaw | 0.547 rad/s | 명령은 0 — **돌면서 걷습니다** |
| 추론 시간 | 0.15 ms/스텝 | 제어 주기 20ms 의 0.8% |

### 🔴 실물에 올리지 마십시오

**무릎이 서보 정격의 1.78배로 움직여야 합니다.** 그대로 실행하면 서보가 명령을
따라가지 못하거나 손상됩니다. `rl/eval.py` 가 이것을 자동으로 판정해 경고합니다 —
정책의 명령은 규칙 기반과 달리 예측할 수 없으므로, **실물에 올리기 전에 여기서
거르는 것**이 이 스크립트의 목적입니다.

이것이 현재의 정직한 상태입니다. 정책은 하드웨어가 낼 수 없는 명령으로 속도를
얻었고, 그 사실이 배포 전에 걸러졌습니다.

### 알려진 한계

1. **명령 범위의 위쪽에서만 추종합니다.** vx 0.3 부근에서 걷고, 0.2 이하를 주면
   제자리에 섭니다. 고장이 아니라 학습이 그 구간만 성립한 상태입니다.
2. **도메인 랜덤화 하에서는 성립하지 않습니다.** 랜덤화를 켜고 학습하면 다섯 가지
   설정 모두 "제자리에 서기"로 수렴했습니다. 원인을 항목별로 갈라 두었습니다 —
   마찰 ×[0.6,1.4] 이 속도를 78%, 서보 영점 ±8° 가 71% 깎습니다. 넘어뜨리는 것이
   아니라 속도를 죽이므로, 걸어도 못 벌고 정지가 이깁니다.
3. **명령하지 않은 yaw 회전**이 있습니다. 돌면서 전진합니다.

### 다음

무릎 각속도를 보상에 제약으로 넣어 정격 안으로 들어오게 하는 것이 먼저입니다.
속도가 3.4배 나온다는 것은 여유가 있다는 뜻이므로, 속도를 일부 포기하고 슬루를
낮추는 교환이 가능할 것으로 봅니다. 실물 이식은 그 뒤입니다.
