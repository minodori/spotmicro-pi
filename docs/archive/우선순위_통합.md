### B-1 이 최대 리스크입니다

3분 영상은 소재가 있다고 되는 게 아닙니다. **구성 → 편집 → 자막 → 렌더**로 하루가
걸립니다. 심사위원이 무음으로 볼 수 있어 자막이 필수이고, 3분 초과는 규정 위반입니다.
8/26 에 몰면 터집니다. **8/23(일)을 통으로 비워야 합니다.**

### B-5 — 운영규정 의무 사항

제9조②3-가: 자체 개발 모델은 **가중치 전체를 승인 절차 없이 누구나 접근 가능한
공개저장소에 게시**해야 합니다. RL 이 출품 핵심이라 유형 3 해당을 피할 수 없습니다.

> **Hugging Face 대신 저장소 `checkpoints/` 에 직접 커밋을 제안합니다.**
> `policy.zip` + `vecnormalize.pkl` 이 수 MB 라 부담 없고, 계정·토큰 절차가 없으며,
> "공개저장소 게시" 요건을 동일하게 충족합니다. 붙임2 에 그 URL 을 적으면 끝입니다.

### B-6 — 형식 실수는 실격입니다

```
HWP(HWPX) 또는 DOC(DOCX) 1부  +  PDF 변환본 1부   = 2개 파일
맑은고딕 본문 10pt / 여백 변경 금지 / 5페이지 이내
안내 페이지 삭제 필수 / 회색 가이드 문구 삭제
파일명: 2026 오픈소스 개발자대회 결과보고서_[접수번호](KINETIQ)
```
