## 2. plate.stl 실측

바이너리 STL(4,276 삼각형)에서 메시를 직접 슬라이싱해 측정한 값이다. 소스 CAD가 없어 STL 지오메트리가 유일한 근거다.

> **주의** — plate.stl은 현재 URDF·파이썬 코드 어디에서도 참조되지 않는 고아 파트다. 업스트림 KDY/Thingiverse 세트([thing:3445283](https://www.thingiverse.com/thing:3445283), [STL/attribution_card.html](../../STL/attribution_card.html)) 상속본.

### 2.1 좌표계 정의

STL 원본 메시 축은 **X–Z가 판면, Y가 두께**다. 이 문서에서는 판의 최소 코너를 원점으로 옮긴 **플레이트 로컬 좌표 (U, V)** 를 쓴다.

```
U = X − 1.5     (0 … 107)     ← 판 짧은 변 방향
V = Z + 5.1     (0 … 95)      ← 판 긴 변 방향
Y = 0 … 7                     ← 두께 방향 (그대로)
```

| 메시 원본 | 범위 | 크기 |
|---|---|---|
| X | 1.50 … 108.50 | **107.00** |
| Y | 0.00 … 7.00 | 7.00 |
| Z | −5.10 … 89.90 | **95.00** |

### 2.2 외곽 및 단면

| 항목 | 값 |
|---|---|
| 외곽 | **107.00 × 95.00 mm** 라운드 사각형 |
| 코너 R | **R1.0** |
| 판 두께 | **2.90 mm** (Y = 0 → 2.90) |
| 전체 높이 | 7.00 mm (보스 포함) |
| 판 상면(보스 없는 면) 면적 | 8,856.8 mm² |
| 판 하면 면적 | 10,050.9 mm² |
| 외곽 폐곡선 면적 | **10,164.1 mm²** |

### 2.3 앞/뒤 면 구분

두 면의 성격이 완전히 다르다. 큰 보드(RPi 5)는 **Y = 0 면**이 유리하다.

| 면 | 특징 | 방해물 |
|---|---|---|
| **Y = 0 면** (평면) | 완전 평면. 육각 너트 포켓 4개만 개구 | 포켓 4개 (Ø6.6 원형 개구) |
| **Y = 2.90 면** (보스면) | 원통 보스 5개가 4.10 mm 돌출 | 보스 5개 (기부 최대 Ø16.13) |

### 2.4 기존 홀 / 보스 위치

```
V=95 ┌───────────────────────────────────────┐
     │                                       │
  86 │                              ○ ▣      │   ▣ = 보스 + Ø3.2 관통홀
     │                                       │   ● = 보스만 (홀 없음)
  72 │   ●                                   │
     │                                       │
  58 │                              ○ ▣      │
     │                                       │
  35 │                       ▣ ○ ▣           │
     │                                       │
   0 └───────────────────────────────────────┘
     U=0                                  U=107
```

| # | 로컬 (U, V) | 메시 (X, Z) | 관통홀 Ø | 너트 포켓 | 보스 |
|:-:|---|---|:---:|---|---|
| 1 | (46.0, 35.0) | (47.5, 29.9) | **Ø3.20** | 육각 5.72 AF, 깊이 3.0 | ○ (obround로 #2와 병합) |
| 2 | (61.0, 35.0) | (62.5, 29.9) | **Ø3.20** | 육각 5.72 AF, 깊이 3.0 | ○ (obround로 #1과 병합) |
| 3 | (69.5, 58.1) | (71.0, 53.0) | **Ø3.20** | 육각 5.72 AF, 깊이 3.0 | ○ Ø10 |
| 4 | (69.5, 86.1) | (71.0, 81.0) | **Ø3.20** | 육각 5.72 AF, 깊이 3.0 | ○ Ø10 |
| 5 | (8.5, 72.1) | (10.0, 67.0) | — | — | ○ Ø10, **홀 없음** |

**보스 형상** (Y = 2.90 → 7.00, 높이 4.10 mm)

| Y | 외경 |
|:---:|:---:|
| 3.05 | Ø16.13 (필렛 기부) |
| 5.00 | Ø11.08 |
| 6.50 | Ø10.09 |
| 7.00 | **Ø10.00** (상단 평면) |

- #1·#2 보스는 하나의 **obround 28.94 × 13.98** 로 병합되어 있다.
- Ø3.20 관통홀은 Y = 3.00 → 7.00 구간(보스 내부)만 뚫려 있다.
- **육각 너트 포켓**: Y = 0 → 3.00, 대변 5.72 / 대각 6.60 → **M3 너트(5.5 AF) 캡처용**. 즉 M3 나사는 보스 쪽(Y=7)에서 들어와 Y=0 면의 너트에 물린다.

**홀 피치**: #1↔#2 = **15.00 mm**, #3↔#4 = **28.00 mm**.
직사각 패턴이 아니고 어떤 표준 보드 풋프린트와도 맞지 않는다 → **보드 마운팅용이 아니라 판–프레임 체결용**이다. 신규 보드 홀 설계 시 이 4개는 그대로 보존해야 한다.

## 3. 부품별 외곽 치수 & 마운팅 홀

각 부품 로컬 좌표계는 **보드 좌하단 코너 = (0, 0)**, 가로가 긴 변이다.

### 3.1 Raspberry Pi 5 — 앞면 1개

출처: Raspberry Pi Ltd 공식 기구 도면 `RP-008347-DS-1` (수치 직접 판독)

| 항목 | 값 |
|---|---|
| 보드 외곽 | **85.0 × 56.0 mm** |
| PCB 두께 | 1.4 mm |
| 마운팅 홀 | **4 × Ø2.7 mm** (M2.5) |
| 홀 패턴 | **58.0 × 49.0 mm** |
| 코너 R | R3.0 |

**홀 좌표** (원점 = USB-C / microSD 쪽 코너)

| 홀 | (x, y) |
|:---:|---|
| A | (3.5, 3.5) |
| B | (61.5, 3.5) |
| C | (3.5, 52.5) |
| D | (61.5, 52.5) |

```
   y=56 ┌─────────────────────────────────────────┐
        │  C                    D                 │
        │  ○                    ○                 │  ← 40핀 GPIO 헤더 변
        │                                         │
        │                                         │
        │  ○                    ○                 │
        │  A                    B                 │
      0 └─────────────────────────────────────────┘
        x=0  3.5 ├──── 58.0 ────┤ 61.5      23.5  85
```

> **비대칭 주의** — 홀은 보드 중심 대칭이 아니다. 짧은 쪽 여백 3.5 mm, 반대쪽(USB/이더넷 쪽) 여백 **23.5 mm**. 세로 방향만 3.5 / 3.5 대칭(3.5 + 49 + 3.5 = 56).

**기타 도면 수치**: 이더넷 커넥터 세로 중심 10.2, USB 포트 중심 29.1 / 47, 마이크로HDMI 위치 11.2 / 25.8 / 39.2, 바닥면 최대 부품 높이 3 mm.
→ **하면 클리어런스 확보를 위해 스탠드오프 4 mm 이상** 필요.

### 3.4 PCA9685 (HW-370) — 배면 2개

출처: Adafruit 16-Channel 12-bit PWM/Servo Driver (제품 815) 기구 스펙.
실물 확인: 사진 판독으로 실크 `PCA9685 16 x 12-bit PWM` / `HW-370` — Adafruit 레이아웃 클론이며 4코너 홀 배치 동일.

| 항목 | 값 |
|---|---|
| 보드 외곽 | **62.5 × 25.4 mm** (2.5" × 1", 헤더·단자대 제외) |
| PCB 두께 | 3 mm |
| 마운팅 홀 | **4 × Ø2.5 mm** (0.1", M2.5) |
| 홀 패턴 | **55.88 × 19.05 mm** (2.20" × 0.75") |

**홀 좌표** (원점 = 보드 코너)

| 홀 | (x, y) |
|:---:|---|
| A | (3.31, 3.18) |
| B | (59.19, 3.18) |
| C | (3.31, 22.23) |
| D | (59.19, 22.23) |

```
 y=25.4 ┌───────────────────────────────────────┐
        │ ○ C                              D ○  │  ← 서보 3핀 헤더 변
        │                                       │
        │ ○ A                              B ○  │
      0 └───────────────────────────────────────┘
        x=0 3.31├────── 55.88 ──────┤59.19   62.5
```

- 4코너 대칭 (모서리 여백 3.31 / 3.18 mm).
- **높이 여유**: 서보 헤더가 PCB 위로 약 9 mm, 아래로 3 mm 돌출. 스탠드오프 **4 mm 이상** + 헤더 위쪽 12 mm 클리어런스 필요.
- V+ 초록 단자대가 보드 한쪽 면에서 약 10 mm 튀어나온다.

### 3.5 LiPo 배터리 — 배면 1개

실물: **KinPower 4000mAh** (라벨상 11.1V / 3S). [images/Power_PreInstall_backside.JPG](images/Power_PreInstall_backside.JPG) 에서 판독.

**⚠ 1차 자료 없음.** 리포지터리에 치수 없고, KinPower 브랜드 데이터시트도 확인 불가. 동급 4000mAh 3S 팩의 시판 치수 편차가 크다:

| 제조사 | 치수 (L × W × H) |
|---|---|
| Gens ace 4000mAh 3S 60C | 131.0 × 42.9 × 24.0 |
| 범용 LP3SB | 138 × 41 × 27 |
| Spektrum 4000mAh 3S 30C | 140 × 43 × 24 |
| Turnigy 4000mAh 3S 30C | 144 × 50 × 22 |

| 항목 | 값 |
|---|---|
| 외곽 | **131 ~ 144 × 41 ~ 50 × 22 ~ 27 mm** (실측 필요) |
| 마운팅 홀 | **없음** |
| 고정 방식 | 벨크로 스트랩 / 케이블타이 |

> **길이가 플레이트를 넘는다.** 어떤 값이든 팩 길이(131 mm 이상)가 플레이트 최대 변(95 mm)보다 길다. 현재 조립품 사진에서도 배터리는 베이를 관통해 양쪽으로 걸쳐 있다. → 배터리는 **홀이 아니라 스트랩 슬롯**으로 잡고, 슬롯 간격은 팩 길이가 아니라 **팩 폭(41~50 mm)** 기준으로 잡는 것이 맞다.
>
> 리포지터리 내 배터리 스펙이 문서마다 다르다 — [work01.md:293](work01.md) `3300mAh`, [work05.md:75](work05.md) `7.4V 2S`, [work08.md:179](work08.md) `11.1V 5200mAh`, [images/diagram_v1.1.png](images/diagram_v1.1.png) `Ovonic CNHL 5000mAh 3S1P`. **실장된 것은 KinPower 4000mAh 3S** 이며 사진이 유일한 근거다.
