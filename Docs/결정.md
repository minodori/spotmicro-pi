## 4. 로봇 켜지면 할 일 (CTO 유지)

민호님이 CM4 를 켤 수 있을 때 통째로 실행. **순서 중요.**

### 8/20 세션에서 끝난 것

| 단계 | 결과 |
|---|---|
| 코드 검증 (import·오프셋·회전) | ✅ 서보 무동작으로 확인 |
| **1단계** 매단 기립 | ✅ 범위 초과 없음 |
| **2단계** 매단 보행, 상태판 | ✅ 네발지지 71%, **무릎슬루 323°/s (시뮬 318 대비 2%)**, 이론속도 50mm/s |

**슬루 실측기가 검증됐습니다.** 로봇 값과 시뮬 스윕이 2% 안에서 일치하므로,
아래 사다리를 이 숫자를 보며 올라가면 됩니다.

### 다음에 켜면 여기부터

1. **3단계** 걷는 중 주기 슬라이더 1400 → 2800. **다리가 튀면 안 됨** (위상 누적 검증)
2. **4단계** 회전 `q`×3 (Sa=9). 스윙↔접지 전환에서 발 튐 없어야 함
3. **5단계 — 안전핀.** 지면, 트림 +7, 현재 설정으로 **20초 주행 거리 측정 + 옆에서 촬영**
   - 고정 시간(20초)에 간 거리를 잰다. "1m 까지 몇 초"는 로봇이 새면 안 끝남
   - 줄자가 화면에 같이 들어가게 촬영 → 시연영상 소재 겸용
   - 좌우 편차와 넘어짐 여부도 같이 기록 (보고서의 "연속 보행 거리/시간")
4. **6단계 튜닝 — 사다리로.** 각 칸에서 슬루를 보며 올라간다

   | 조작 | 설정 | 예상 슬루 | 시뮬 속도 |
   |---|---|---:|---:|
   | — | 현재 `Tt1400 Sh20 Sl-70` | 323 | 49mm/s |
   | `c`×2 | `Tt1600` | ~350 | |
   | `r`×6 | `Tt1600 Sh26` | ~380 | |
   | `w`×3 | `Tt1600 Sh26 Sl-100` | ~410 | 60mm/s |
   | `w`×2 | **`Tt1600 Sh26 Sl-120`** | **~456** | **70mm/s** |

   **`Sl-140` 이상 금지** — 슬루 523 으로 정격 96%. 화면이 490 에서 경고한다.
   ~~`Tt2800 Sh30 Sl-120`~~ 은 폐기. 시뮬에서 34mm/s 로 현재보다 느림 (아래 로그 22)
5. 튜닝 후 재측정 + 재촬영
6. 하드웨어 라벨 확인 (서보 12개, 벅 모델명, 배터리 용량) — 보고서 개발환경 표
7. 링크별 질량 계량 (다리 1개 ≈ 255g, 몸통 ≈ 1180g 예상) — BA-2 회신용
8. 여유 시 회전 보행 촬영

> 폰 UI 는 페이지를 처음 한 번만 받아온다. 코드를 갱신했으면 **폰에서 새로고침**해야
